About TaskFlow

TaskFlow is a lightweight task management web application designed to help individuals and teams organize their work efficiently.


How to Use

  • Go to Home to see your task summary.
  • Click Add Task to create a new task.
  • View all tasks from the Task List page.
  • Click any task to see its details on the Task Detail page.
  • Mark tasks complete or delete them from the detail view.
